# Household Financial Pressure

We're asking about your household's money situation — how you'd handle an
unexpected cost, what you've cut back on, and how you see the economy.

Read the respondent context, then complete every question in the questionnaire.
Answer as yourself, about your own household.

## How to answer

- Read `input/context.md` before you start.
- Answer every required question.
- For multiple-choice, use the listed option ids.
- For "select all that apply", return a list of option ids. If nothing applies,
  return the explicit "None of these" option rather than an empty list.
- For rating scales, use a whole number in the given range.
- Answer accurately, not reassuringly. Saying you could not cover a cost, that
  you borrowed, or that you skipped care are all normal answers here.
- Give the answer alone unless a question also asks for a short reason.
